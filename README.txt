MC WATCHES - WEBSITE FILES

Files:
- index.html: website content
- styles.css: design
- CNAME: custom domain setting for GitHub Pages

Important before launch:
1. Replace the temporary MC graphic with the final logo or a real product image later.
2. Do not publish brand names, authenticity, materials, water resistance, warranty, or origin unless verified.
3. Confirm delivery charges and return conditions before adding them.

GitHub Pages setup:
1. Create a public repository named mc-watches-site.
2. Upload index.html, styles.css and CNAME.
3. In Settings > Pages, select Deploy from a branch, main, /root.
4. In GoDaddy DNS, point the www CNAME to YOUR-GITHUB-USERNAME.github.io.
5. Follow GitHub's current custom-domain instructions for the root domain before changing A records.
